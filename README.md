# Delhi, Free

Free cultural events across Delhi NCR, 29 Oct – 30 Nov 2026. 51 events,
searchable by neighbourhood or pincode, sorted by distance from wherever you are.

Live at **https://iambesttttduhh.github.io/delhi-free/**

## What's here

- `index.html` — the whole page: markup, styles and script
- `img/` — 51 photographs, each at 480w and 900w as WebP
- `fonts/` — Anton, Space Grotesk and JetBrains Mono, self-hosted (SIL OFL)
- `robots.txt`, `sitemap.xml` — for search engines
- `google51357efdab8f1c65.html` — Google Search Console ownership check

No build step, no dependencies, no framework. The page makes exactly one network
request of its own: the optional air-quality reading.

## Hosting

GitHub Pages, serving `main` at the repository root. Push to `main` and it
rebuilds automatically.

## Notes

- Events were checked against each organiser's own listing on 29–30 October 2026.
- Times and prices change; call the venue before travelling.
- Photographs are from Wikimedia Commons under their stated licences and are
  credited in the page footer.

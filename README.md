# Delhi, Free

Free cultural events across Delhi NCR, 29 Oct – 30 Nov 2026. 51 events,
searchable by neighbourhood or pincode, sorted by distance from wherever you are.

## What's here

- `index.html` — the whole site: markup, styles and script
- `img/` — 51 photographs, each at 480w and 900w as WebP

No build step, no dependencies, no framework.
